DIGISCAN: SUPABASE EN GITHUB PAGES

De applicatie blijft volledig geschikt voor GitHub Pages. GitHub Pages host alleen
de publieke frontend. Een Supabase Edge Function verwerkt de opslag veilig.

STATUS 6 SEPTEMBER 2026

- Supabase-project DigitaleGeletterdheid is gekoppeld.
- Tabellen scans en responses zijn aangemaakt en RLS is ingeschakeld.
- Edge Function submit-scan is gepubliceerd.
- Opslag is getest via de API en via de volledige website.
- De testgegevens zijn na controle verwijderd; de database is schoon.
- Resultatenmail via Strato-SMTP: zie de sectie RESULTATENMAIL hieronder.

1. SUPABASE AANMAKEN

- Maak een project op https://supabase.com.
- Open SQL Editor en voer de volledige inhoud van supabase/schema.sql uit.
- Noteer bij Project Settings > API:
  - Project URL
  - anon/public key
- Vul deze twee publieke waarden in config.js in.
- Plaats NOOIT de service-role key in config.js of GitHub.

2. EDGE FUNCTION PUBLICEREN

Voer vanuit de projectmap uit:

  npx supabase login
  npx supabase link --project-ref JOUW_PROJECT_REF
  npx supabase secrets set ALLOWED_ORIGIN=https://JOUW_GITHUB_NAAM.github.io
  npx supabase functions deploy submit-scan

SUPABASE_URL en SUPABASE_SERVICE_ROLE_KEY worden automatisch beschikbaar gesteld
aan de Edge Functions. Zet die geheime waarden niet in de frontend.

3. GITHUB PAGES

- Commit en push de projectbestanden naar GitHub.
- Open repository Settings > Pages.
- Kies Deploy from a branch, de branch main en map /(root).
- Open daarna de gepubliceerde URL en voer een volledige testscan uit.

4. CONTROLE

- Controleer in Supabase Table Editor of scans en responses worden gevuld.
- Stel ALLOWED_ORIGIN exact in op de oorsprong van de website, zonder pad erachter.

RESULTATENMAIL VIA STRATO-SMTP (meestersonline.nl)

De resultatenmail bevat een bedankbericht, het spinnenweb (server-side gegenereerd
als PNG, dus op elk apparaat identiek), de scoretabel en de aanbevolen route.
Verzenden gebeurt rechtstreeks via de SMTP-server van Strato met een eigen
mailbox op meestersonline.nl. Er zijn GEEN DNS-wijzigingen nodig: Strato heeft
SPF en DKIM voor de eigen mailservers al geregeld.

Stap 1 - Mailbox aanmaken bij Strato
- Log in op de Strato klantenlogin > pakket > E-mail > E-mailbeheer.
- Maak een nieuwe mailbox aan, bijvoorbeeld: digiscan@meestersonline.nl.
- Kies een sterk wachtwoord en noteer het (dit wordt een Supabase-secret).

Stap 2 - Secrets instellen en functie publiceren
Voer vanuit de projectmap uit:

  npx supabase secrets set SMTP_HOST=smtp.strato.com
  npx supabase secrets set SMTP_PORT=465
  npx supabase secrets set SMTP_USER=digiscan@meestersonline.nl
  npx supabase secrets set SMTP_PASS=HET_MAILBOX_WACHTWOORD
  npx supabase secrets set "MAIL_FROM=DigiScan <digiscan@meestersonline.nl>"
  npx supabase functions deploy send-results

Let op: het afzenderadres in MAIL_FROM moet hetzelfde adres zijn als SMTP_USER,
anders weigert Strato de verzending.

Deploy-tip bij een zakelijk netwerk met eigen TLS-certificaat (foutmelding
"TransportError"): zet eerst deze variabele en deploy daarna opnieuw:

  $env:NODE_TLS_REJECT_UNAUTHORIZED='0'
  npx supabase functions deploy send-results --project-ref dnmvliygdajdqrvzzagp

Stap 3 - Testen
- Vul op de website een volledige scan in.
- Vul op de resultatenpagina een eigen e-mailadres in en klik op Verstuur.
- Controleer de mail (en de spamfolder): bedanktekst, spinnenweb en scoretabel.
- Controleer in Supabase of email_deliveries een regel heeft gekregen.

Beperkingen die al zijn ingebouwd:
- Maximaal 3 e-mails per individuele scan per 24 uur. Dit is een
  anti-misbruikmaatregel per invuller (bijv. voor een tweede poging na een
  typefout). Elke deelnemer heeft een eigen scan, dus een heel team kan
  gewoon tegelijk invullen en mailen.
- Strato hanteert eigen verzendlimieten per mailbox (ruim voldoende voor
  normaal gebruik zoals een teamsessie).
- E-mailadressen worden nooit in de database opgeslagen.

PRIVACY

- E-mailadressen worden alleen gebruikt voor directe verzending via de eigen
  Strato-mailbox en worden niet in de database opgeslagen.
- Leg in een privacyverklaring uit wat wordt opgeslagen, waarom, hoe lang en hoe
  een deelnemer een verwijderverzoek kan indienen.
- Spreek een bewaartermijn af en verwijder oudere scans periodiek.
